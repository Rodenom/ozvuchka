# Озвучка нашим голосом на бесплатной видеокарте

Открыть тетрадь одним кликом:

**https://colab.research.google.com/github/Rodenom/ozvuchka/blob/main/ozvuchka.ipynb**

Порядок:
1. Сверху «Среда выполнения» → «Сменить среду выполнения» → **T4 GPU** → Сохранить.
2. Вставить текст выпуска в ячейку 3.
3. «Среда выполнения» → «Выполнить все».

Первый запуск ставит модель — 3–5 минут. Дальше текст на 2500 знаков озвучивается
примерно за две минуты, готовый mp3 скачивается сам.

Ручки в ячейке 2: скорость чтения и дробление длинных фраз на части.

В `sample/` лежат 25 секунд голоса, с которого снимается тембр, и текст этих
25 секунд слово в слово. Чтобы сменить голос — заменить оба файла вместе.
